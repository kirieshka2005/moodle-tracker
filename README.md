# 🎯 Moodle Tracker

Система мониторинга дедлайнов для платформы МИСИС (newlms.misis.ru).

## Быстрый старт

```bash
pip install -r requirements.txt
python run.py
```

Открой http://127.0.0.1:5000

## Безопасность

Пароль **никогда не сохраняется**. При входе он используется однократно для получения токена Moodle и сразу удаляется из памяти. В сессии хранится только токен.

## Функции

- Тёмная/светлая тема
- Сортировка и фильтрация дедлайнов
- Accordion-группировка по предметам
- Прогресс-бар выполненных задач
- Трекер загрузки следующей недели
- Градация просрочек 
- Ручное удаление и пометка задач как выполненных
- Приоритизация задач
- Поиск по задачам
- TODO-лист
- Экспорт: TXT, Markdown, JSON, CSV, ICS, Заметки
- Адаптивный дизайн (мобильный + десктоп)
